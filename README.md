# 🎮 Fake FF Panel

> ⚠️ **Entertainment & Educational Purposes Only**

Fake FF Panel is an Android entertainment application that simulates a game hacking panel interface with a hacker-style aesthetic. **No actual game modification or cheating functionality is included.**

---

## 🎨 Visual Design

- Black background throughout the app
- Red accent color for all text and buttons
- Hacker-style dark theme
- Clean, professional-looking interface

---

## 🎯 Features

| Feature | Description |
|---------|-------------|
| **Activation Flow** | Tap "ACTIVATE PANEL" to unlock the simulated panel |
| **8 Cheat Categories** | Interactive buttons with emoji icons |
| **Popup Notifications** | Each category shows a fun "ENABLED!" popup |
| **Built-in Disclaimer** | Clear messaging that this is simulation only |

### Cheat Categories
- 🎯 Aim Bot
- 💚 Unlimited Health
- 🎯 Headshot Rate
- ⚡ Speed Hack
- 🔫 No Recoil
- 👁️ Wall Hack
- 💀 One Shot Kill
- 🛡️ Auto Shield

## 🤖 CI/CD with GitHub Actions

This app is automatically built into an APK using GitHub Actions.

| Trigger | Action |
|---------|--------|
| Push to `main` | Auto-build APK |
| Pull Request | Verify build |
| Manual | `workflow_dispatch` |

### Download APK
1. Go to **Actions** tab
2. Select the latest workflow run
3. Download `FakeFFPanel-APK` artifact
